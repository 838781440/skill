# 输出模板

## 模板1：决策锚定确认

```
🎯 决策锚定确认：
• 主体：[信息]
• 内容：[信息]
• 窗口：[信息]
• 约束：[信息]

信息完备，进入主席预审。
```

不完整时：
```
⚠️ 决策锚定不完整，缺少：[缺失项]
请补充后再进入审议。私董会不接受模糊决策。
```
