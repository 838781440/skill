# 调度师配置决策记录

> 2026年6月7日 — 从 v1 升级到 v2 的配置决策汇总

## 废弃的旧模式（v1）

旧版调度师有两个模式，已在 v2 中移除：
- **流水线方式（Agency Orchestrator）** — A→B→C 单线接力
- **圆桌讨论方式（delegate_task 4轮辩论）** — 固定4轮，角色名硬编码

## v2 最终配置

| 配置项 | 快速模式 | 深度模式 |
|:-------|:--------|:--------|
| 专家数 | 3~5 个 | 6~10 个 |
| 每人工具上限 | ≤ 5 次 | ≤ 15 次 |
| 目标耗时 | ≤ 60 秒 | 不限（追求完整证据链） |
| 执行方式 | 所有专家并行 | 按依赖顺序 + 交叉审查 |

## 触发方式

不需要加"调度师"前缀，直接说：
- 「快速分析 XX」
- 「深度分析 XX」
- 「从 XX 方面再分析一下」

## 核心规则

1. **证据门禁（强制）** — 每条结论必须标注 🔵🟡🟠🔴 证据等级，末尾附证据清单
2. **过程可见（强制）** — 每个专家的原始输出必须逐条展示给用户，不能只给汇总
3. **不存 gbrain（强制）** — 分析结果只在对话中展示，不持久化到 gbrain
